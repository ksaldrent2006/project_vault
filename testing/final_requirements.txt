Final Project Requirements:

REQ-1: As a user, I would like to view the available projects for the different departments. (3 pts)
REQ-2: As a user, I want to be able to see the project information for each project. (3 pts)
REQ-3: As a user, I should be able to log in and log out if I have an etown email. (7 pts)
REQ-4: As a user, I should be able to edit their profile while considering error handling. (7 pts)
REQ-5: As a user, I would like to create an account. (5 pts)
REQ-6: As a user, I would like to be able to access external repo links. (3 pts)
REQ-7: As a user, I would like to add the project I am working on to the projects library. (7 pts)
REQ-8: As a user, I should be able to edit or delete projects. (5 pts)
REQ-9: As a user, I would like to request to work on a project. (5 pts)
REQ-10: As a user, I would like to be able to add myself to a team. (5 pts)
REQ-11: As a user, I should be able to create a team. (5 pts) 
REQ-12: As a team member, I should be able to identify what team(s) I am on. (3 pts)
REQ-13: As a team member, I should be able to update the progress that my team made on a project. (4 pts)
REQ-14: As a team member, I should be able to access one or many projects. (4 pts)
REQ-15: As a user, I should be able to access my projects progress documentation. (3 pts)
REQ-16: As a user, I should be able to edit a project's progress documentation, such as add project materials, visuals, etc. (5 pts)
REQ-17: As a user, I should be able to see the progress between a certain projects start and end dates. (5 pts)
