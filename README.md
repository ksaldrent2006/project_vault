# project_vault

Project Description:
The goal of this project is to create a database system that stores and organizes project ideas that
can be used by students in the School of Engineering and Computer Science. The system will
allow project information to be easily accessed and maintained so that students can review
available projects and understand their requirements before selecting one.

The database will store information such as the project description, who requested the project,
project requirements, students or teams who have worked on it, the current status of the project,
where previous work was left, and the location of the most recent Git repository.

Project Goal:
- Create a centralized database for storing and organizing project ideas.
